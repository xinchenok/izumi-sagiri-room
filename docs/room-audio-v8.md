# V8 房间专属配音与场景声

- 制作日期：2026-08-13
- 用户目标：每一个房间地点、事件与天气状态都使用自己的配音和场景声，不从页面其他段落借用，也不在房间事件之间复用
- 运行边界：全部音频随静态站点本地发布，只在明确操作后播放，不自动播放、不循环、不调用系统 TTS；接近交互时只做静音预热，不把加载误当成播放
- 机器清单：[`assets/audio/v8/voice-manifest.json`](../assets/audio/v8/voice-manifest.json) 与 [`assets/audio/v8/scene-sound-manifest.json`](../assets/audio/v8/scene-sound-manifest.json)

## 最终声音矩阵

| 地点 / 状态 | 专属角色语音 | 独立场景声 |
| --- | ---: | ---: |
| 画桌旁 | 1 条地点开场 + 3 条事件 | 补完线条、转动画纸、保存提示各 1 段 |
| 床边 | 1 条地点开场 + 3 条事件 | 收回毯角、收起小帐篷、推来靠枕各 1 段 |
| 衣橱边 | 1 条地点开场 + 3 条事件 | 扶稳衣架、掠过布料、并排选衣各 1 段 |
| 窗台 | 1 条地点开场 + 3 条事件 | 关小窗缝、摆好画纸、合上窗帘各 1 段 |
| 雨起 / 雨停 | 2 条天气语音 | 雨落窗外、雨停见月各 1 段 |
| **合计** | **18 条** | **14 段** |

`CONTENT.livingRoom.voices` 是房间角色语音的唯一运行时入口。四个地点的 `voice`、十二个 `moments[].voice` 与两个天气状态分别指向十八个不同 ID；这些 ID 不存在于主线 `CONTENT.voiceLines`，文件也全部位于 `assets/audio/v8/voice/`，因此不会借用主线的二十二句 AivisSpeech 回答。

## 合成来源与后期

房间语音使用 [Piper Plus 0.6.0](https://github.com/ayutaz/piper-plus) 与 [ayousanz/piper-plus-tsukuyomi-chan](https://huggingface.co/ayousanz/piper-plus-tsukuyomi-chan) 预训练模型本地生成。模型卡声明训练数据来自[つくよみちゃんコーパス](https://tyc.rei-yumesaki.net/material/corpus/)；页面页脚长期保留模型来源和语料条款链接。

- 没有采集角色动画音轨，没有训练、微调或克隆藤田茜等真实声优声纹。
- 没有提供参考音频或说话人克隆向量；按 Piper Plus Python 参考实现，在模型要求前向兼容输入时传 256 维零向量与 `speaker_embedding_mask=0`，回退到训练声线。
- 合成参数固定为 `language=ja`、`noise_scale=0.667`、`length_scale=1.5`、`noise_w=0.8`。
- 原始输出为 22.05 kHz 单声道 WAV；最终经过 70 Hz 高通、10.5 kHz 低通和 `I=-17 / TP=-1.5 / LRA=7` 响度处理，编码成 44.1 kHz、单声道、160 kbps MP3。
- 十八个最终文件的实测综合响度约为 -15.2～-18.3 LUFS，峰值约为 -1.9～-2.8 dBFS；每个文件都能由 FFmpeg 解码。

模型与配置本身不进入仓库；清单保存模型 revision、模型 SHA-256、完整文本和最终音频哈希，便于以后核对来源与变化。

## 十四段独立场景声

场景声使用 FFmpeg 噪声源、频段、包络、短音色层和立体声位置程序化制作，不下载第三方录音素材。十二个地点事件与两个天气状态各有一个文件，统一为 48 kHz、立体声、192 kbps MP3。它们不是循环环境音，只承担一次操作的短触感。

V7 的四段 44.1 kHz 单声道拟音仍留在 `assets/audio/v7/` 供历史复现，但 `script.js` 已没有运行时引用。雨起与雨停也没有借用窗台的关窗或窗帘文件，分别使用 `weather-rain-window.mp3` 与 `weather-clear-window.mp3`。

## 雨线与室内边界

V7 雨线曾铺满整个房间取景框，容易产生“室内在下雨”的误读。V8 首次缩窄后仍用了过大的矩形区域，会压到窗帘、窗框或部分室内物件；当前实现进一步以能明确辨认的单块室外玻璃为硬边界：床边完全隐藏，画桌与共同创作舞台只使用右上窗格，衣橱只使用最右上窄窗格，窗台只使用月亮所在的右上窗格。所有雨层宽度不超过取景框 19%、高度不超过 21%，不覆盖人物、窗帘、灯具、床、桌面或地板。天气语音也明确说明雨只在窗外。

## 点击响应与预热

旧实现让角色语音和场景声分别共用一个播放器；每次点击都先停止旧音频、替换 `src`、调用 `load()`，慢网与连续点击会产生可见等待，前一次加载也可能被后一次替换。当前实现为每个音频文件保留独立播放器，并在对应语音按钮或连续房间进入预备范围、房门首次打开时，以低网络优先级完整读取文件、转换为本页 Blob 源。预热本身没有 `play()`，因此仍然符合“只有用户操作后播放”。

- 内存源已经就绪时，点击直接从本地 Blob 开始，不再临时发媒体请求或替换共享 `src`。
- 尚未就绪时立即显示“正在准备”，本次点击仍可使用仓库内原文件播放。
- 预热请求瞬时失败时不锁死条目；媒体元素会重新加载原文件，后续点击可以恢复。
- 新点击仍停止上一条角色语音或场景声，过时请求的 `AbortError` 不覆盖当前字幕和状态。

## 控制与失败降级

- “只看角色字幕”只静音角色语音；触发后仍展示日文、简体中文字幕、场景标签、表情和反应。
- “场景声”只控制十四段物件 / 天气声；关闭后不能连带静音角色语音。
- 两类声音都不会在地点切换、进入视口或自主动画时自动播放。
- 新语音会停止上一条角色语音；每段场景声有自己的缓存播放器，仍不进入角色音量控制。
- 角色音频加载失败时保留双语字幕并显示可恢复说明；场景声失败时保留地点事件、画面和文字状态。

## 日语字幕字体

原有 ZCOOL KuaiLe 字体不含完整日文假名。V8 新增 Noto Sans JP 当前页面字符子集 `assets/fonts/NotoSansJP-Room-Subset.woff2`，只让 `lang="ja"` 的字幕优先使用它，并保留 [`OFL-NotoSansJP.txt`](../assets/fonts/OFL-NotoSansJP.txt)。页面仍不远程热链字体。

## 验收

发布前必须继续满足以下门禁：

- 桌面 1440 × 1000 与手机 390 × 844 实际点击：4 条地点语音、12 条事件语音、2 条天气语音全部是十八个不同 V8 文件。
- 同样路径确认 12 段事件声和 2 段天气声全部不同，场景声关闭后角色语音仍可播放。
- 故障注入阻断 `room-desk-intro.mp3`，双语字幕与错误说明仍保留。
- 床边无雨线；连续房间四个地点和共同创作舞台的雨层均逐项检查，宽度不超过取景框 19%、高度不超过 21%，只落在右上室外玻璃，不覆盖人物与任何室内物件。
- 在每个音频请求人为增加 1.2 秒等待的条件下，预热后的房间配音点击不新增网络请求，受控 Chromium 实测约 65–85ms 进入播放状态；首次预热故障注入后可由原文件重试并成功播放。
- 受控 Chromium 截图确认日语字幕无方框缺字，桌面和手机均无横向页面溢出。
- `node --check script.js`、两个 JSON 清单解析、全部音频解码、资源引用、UTF-8 无 BOM与乱码特征扫描通过。
