## 体验合同

V19 在原有互动页前部加入一段不劫持滚轮的七幕连续拜访。访客继续使用浏览器原生纵向滚动，固定舞台根据当前文字段落在两张已解码图片之间切换，同时做低幅镜头推移；没有强制分页、滚动锁、自动跳幕或滚动触发声音。

| 幕 | 关键帧 | 观察热点 | 叙事作用 |
| --- | ---: | ---: | --- |
| 房门 | 4 | 3 | 偷看、侧耳、受惊、开门 |
| 房间 | 4 | 3 | 继续画、停笔、回望、空出椅子 |
| 桌面秘密 | 3 | 3 | 被发现、护住草稿、一起开抽屉 |
| 衣橱 | 4 | 3 | 藏手、举起两套、整理蝴蝶结、等回应 |
| 画册 | 3 | 3 | 藏起画册、从书后看、推近最后一页 |
| 一起画 | 5 | 3 | 收线、眨眼、遮画、害羞停笔、递出成稿 |
| 晚安 | 3 | 3 | 抱玩偶、打呵欠、门边挥手 |

合计 26 张关键帧和 21 个物件热点。每幕另有一个角色热点，用于主动听该幕的角色回答。

## 图片矩阵与纠偏

V19 图片权威清单是 `assets/v19/manifest.json`：

- 8 张竖版母版：3072 × 3840；网页派生图为 720 × 900、1440 × 1800。
- 18 张 4:3 场景母版：3840 × 2880；网页派生图为 480 × 360、720 × 540、1440 × 1080。
- 总计 26 张母版、96 个 WebP；每个 WebP 都有同名 `.webp.json` provenance 边车。
- 精确提示词位于 `assets/v19/prompts/`。
- `identityAnchor`、`styleAnchor`、对应旧图、尺寸、文件大小和 SHA-256 均由清单记录。

首轮 ImageGen 新图虽然保留了动作，却被用户指出存在棕橙色偏、颗粒、油画笔触和整体脏感。该批次完整留在被 Git 忽略的生成期临时目录，没有进入 `assets/v19`。最终批次以主 agent 先校准的一张干净画桌图作为唯一人物 / 画风 / 调色锚点，逐张重新编辑：旧图只保留构图与动作，画风统一为清爽明亮的日系 TV 动画赛璐璐、平整无纹理色块、最多两档硬边阴影、冷白银发、清透肤色和浅木家具。

`tools/build-v19-images.py` 从最终清理源图生成 4K 母版与响应式版本。处理只使用 Pillow Lanczos 尺寸转换和高质量 WebP 编码，不添加锐化、纹理、降噪或调色滤镜；因此不能把 V19 描述成模型原生直接输出 4K，也不能把清晰度归因于后期锐化。

V19 不删除、覆盖或移动旧图。`assets/archive/pre-v19-cinematic-images.json` 固定记录切换前 V18.1 清单中的 107 个 WebP，包括路径、尺寸、文件大小与 SHA-256；更早的 v3–v7、V18 和 V18.1 资产也继续留在原位。

## CinematicDirector

`script.js` 的 `CONTENT.cinematicScenes` 是七幕帧、机位、文字、热点、语音与拟音关系的唯一内容入口；`CinematicDirector` 负责运行时呈现：

1. 舞台使用 `cinematicLayerA` / `cinematicLayerB` 两个图片层，只混合透明度与低幅相机位移，不使用模糊滤镜。
2. `IntersectionObserver` 只在七幕区域接近视口时启用更新和自主动作；离开区域或页面转入后台便停止。
3. `scroll` 与 `resize` 监听均为被动监听，只设置脏标记；DOM 测量与绘制统一合并到下一次 `requestAnimationFrame`。
4. `loadSequence` 防止快速反向滚动时旧图片请求覆盖当前幕；`autonomySequence` 同样取消过期自主反应。
5. 普通舞台在手机读取 720 档、桌面读取 1440 档。默认只预取当前幕下一帧与下一幕首帧。
6. `navigator.connection.saveData` 为真，或网络为 `slow-2g` / `2g` 时，停止邻帧预取；没有发生混合时也不提前请求下一层图片。
7. 每幕停留 4–7 秒后最多出现三次短自主反应；它们不写入浏览器状态、不弹任务，也不播放声音。

每个动作间隔以桌面约 58svh、手机约 48svh 安排；区段最后 14% 通过门边或稿纸方向的裁切引出下一幕。返回已经缓存的帧同样会取消尚未完成的新帧请求，避免快速往返时被迟到结果覆盖。安静模式仅短淡入，系统减少动态固定为首帧。图片失败保留上一张可用图，提供重试。

## 观察对话框

“看看房间”打开原生 `dialog`，并以当前幕的稳定观察帧为起点。稳定帧由 `inspectFrameId` 指定，必须同时包含该幕的三个热点物件；图片使用 `contain` 完整呈现，热点依据实际渲染图片矩形换算坐标，因此竖版门口图在宽屏中也不会丢掉门把。

| 输入 | 支持操作 |
| --- | --- |
| 鼠标 | 拖动平移、滚轮缩放、双击在 100% / 200% 间切换、按钮缩放与复位 |
| 触摸 | 单指拖动、双指缩放、底部按钮缩放与复位 |
| 键盘 | 方向键平移；Shift + 方向键大步移动；`+` / `-` 缩放；Home 复位；Esc 关闭 |

缩放范围固定为 100%–200%，平移按实际图片尺寸与缩放倍数限制；图片未填满某个方向时，该方向不允许继续平移。点击物件后热点暂时隐藏并展示对应反应帧，约一秒后恢复稳定观察帧和热点。弹窗内直接显示双语字幕与两个声音开关。关闭时恢复原滚动位置并归还焦点；图片失败保留上一张可用图或低一档图片，并提供重试和退出入口。

观察模式是唯一主动升级大图的入口：手机使用 1440 档，桌面使用 4K。每幕三个物件热点同时触发该物件独立拟音、对应角色语音、反应帧与双语字幕；角色热点只触发该幕角色语音。鼠标、触摸和键盘都使用原生按钮触发同一逻辑。滚动、自动换帧、打开对话框和页面载入均不自动播放声音。

## 动效偏好

`sagiri-room-state-v2.motionMode` 只有 `lively` 与 `quiet` 两个值，旧状态缺失时回落到 `lively`。

- `lively`：允许双层混合、镜头轻推、自主反应、雨景和既有低幅环境动作。
- `quiet`：保留当前静态帧、七幕文字、观察、热点和主动声音，但停止连续混合、自主反应、雨景与视差。
- 系统 `prefers-reduced-motion: reduce` 始终优先于站内保存值；启用时动效按钮不可更改系统决定，七幕固定显示每幕首帧。
