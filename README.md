# 和泉纱雾的房门里

一个零框架、无后端的个人非盈利同人角色互动页。沿着“轻轻敲门”的叙事，可以在画桌、床边、衣橱和窗台之间移动，观察纱雾正在发生的日常小事；也可以陪她完成一张小猫画、切换五套日常服装、按章节查看秘密画稿，并播放带简体中文字幕的本地日语语音。页面会记住间隔较久的再次拜访，也会把上次共同完成的画留在桌边，但不显示好感度数值。

在线访问：<https://xinchenok.github.io/izumi-sagiri-room/>

## 本地浏览

直接打开 `index.html` 即可使用。推荐当前版本的 Chrome、Edge、Firefox 或 Safari。

## 主要互动

- 敲门后的受惊、害羞与开门表情演出
- “会生活的房间”：沿同一条木轨在画桌、床边、衣橱与窗台移动；每个地点都有自主细节、专属开场语音、三组独立语音事件、键盘方向键和手机横滑支持
- “今晚，陪她画完这一张”共同创作：选择陪伴方式、画面主题、配色与一句具体感想；结果会改变成稿、角色台词和下次回访记忆，没有分数、奖励或失败状态
- 五套服装与衣橱相册切页，包括草莓睡前服与符合家里蹲画师性格的猫耳连帽毯
- 一张完整画桌插画里的五个无常驻标记秘密；停留一会儿会收到一句自然线索，不显示提示按钮
- 十一张分成三章的小故事画稿；主图可进入沉浸暗房，支持方向键、手机滑动与原图细节放大
- 四个主线语音入口、二十二句本地日语回答；普通池以十八句轻声、开心或害羞回答轮换，四句不高兴回答只在短时间连续催门或催稿时出现
- 房间另有十八句不与主线复用的专属日语语音：四个地点开场、十二个地点事件、雨起与雨停各一条；每条都绑定独立 MP3、日文、简体中文字幕、场景名和反应
- 音量、停止与“只看角色字幕”控制；房间另有十二段地点事件声和两段天气声，共十四段独立 48 kHz 立体声场景声，可单独关闭，不自动播放也不循环；音频在对应交互靠近视口时低优先完整预热，点击后直接使用独立内存源，瞬时网络失败会自动重试
- 雨景按每张插画的真实窗格独立裁剪：Canvas 雨滴会被窗框截断，桌边、衣橱、窗台和共同创作使用不同节奏，床边及室内不下雨；窗雨声为 7.224 秒本地多层立体声合成，可由仓库脚本复现
- 三阶段回访文案：初次、逐渐熟悉与主动留门缝，不使用签到或数值好感度
- 随机晚安小纸条

## 使用技术

页面仅使用原生 HTML、CSS 和 JavaScript，不依赖框架、后端或运行时外部服务。状态保存在浏览器本地存储中。首屏、表情与换装使用完整尺寸高质量 WebP，并按屏幕选择 560px 移动版本；共同创作与 V7 衣橱场景使用 1448 × 1086 / 720 × 540 两档本地 WebP。中文标题和日语字幕分别使用 ZCOOL KuaiLe、Noto Sans JP 的当前字符子集 WOFF2，画册与房间场景只在需要时预取；音频预热仍只读取仓库内的已发布文件，不连接运行时语音服务。

## 声音与字体说明

- 语音使用 AivisSpeech 的“天深シノ”模型生成；二十二句回答均为独立合成内容，保留完整 `audio_query`，使用同一模型并按场景选择轻声、普通、开心或情境限定的稍微不高兴表达，遵循 ACML-NC 1.0，仅用于个人非盈利展示。
- 房间专属语音使用 Piper Plus 的“つくよみちゃん”预训练模型生成；十八句均为本次房间独立文本和独立音频，不复用前述二十二句，也不使用说话人克隆。模型输出按其语料条款使用并在页脚保留来源。
- 中文手写标题使用站酷快乐体，日语字幕使用 Noto Sans JP；两者均遵循 SIL Open Font License 1.1，并以本地字符子集加载。
- 页面不包含动画原声、声优声纹克隆或官方截图。
