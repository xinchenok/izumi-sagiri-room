# 和泉纱雾的房门里

一个零框架、无后端的个人非盈利同人角色互动页。沿着“轻轻敲门”的叙事，可以探索纱雾的画桌、切换三套日常服装、查看秘密画稿，并播放带简体中文字幕的本地日语语音。

在线访问：<https://xinchenok.github.io/izumi-sagiri-room/>

## 本地浏览

直接打开 `index.html` 即可使用。推荐当前版本的 Chrome、Edge、Firefox 或 Safari。

## 主要互动

- 敲门后的受惊、害羞与开门表情演出
- 三套服装与衣橱相册切页
- 一张完整画桌插画里的五个可点击秘密和隐藏留言
- 七张连成一段小故事的胶片画稿：床上画画、举起画稿、躲在靠枕后递画、等你夸奖与晚安
- 四个语音入口、十六句不同的本地日语回答；同一轮听完前不重复，并始终显示对应简体中文字幕
- 随机晚安小纸条

## 使用技术

页面仅使用原生 HTML、CSS 和 JavaScript，不依赖框架、后端或运行时外部服务。状态保存在浏览器本地存储中。

## 开发与维护文档

[AI 协作开发与维护手册](docs/ai-assisted-development.md)记录了 AI 协助完成的工作、插画方法、语音模型官方来源与本地合成流程、许可边界、上线验证和后续规划。语音使用预训练模型本地合成，本项目没有训练或克隆声优声纹。

## 声音与字体说明

- 语音使用 AivisSpeech 的“天深シノ”模型生成；十六句回答均为独立合成内容，保留完整 `audio_query`，使用同一模型并按场景选择轻声、普通、开心或稍微不高兴的表达，遵循 ACML-NC 1.0，仅用于个人非盈利展示。
- 手写标题字体为站酷快乐体，遵循 SIL Open Font License 1.1。
- 页面不包含动画原声、声优声纹克隆或官方截图。
