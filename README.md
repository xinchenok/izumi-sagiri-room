# 和泉纱雾的房门里

一个零框架、无后端的个人非盈利同人角色互动页。访客先用原生纵向滚动走过“房门—房间—桌面秘密—衣橱—画册—一起画—晚安”七幕连续镜头，也可以打开观察模式放大画面、触碰物件并主动听她回应；原有画桌、床边、衣橱、窗台、换装、章节画廊、深夜陪画与晚安纸条仍完整保留。页面会保存未完成的陪画进度与真实发生的画稿、房间动作、换装和纸条，但不显示好感度数值。

在线访问：<https://xinchenok.github.io/izumi-sagiri-room/>

当前公开版本为 V19.0.1，缓存标识 `20260909-1`，已完成远端 CI、GitHub Pages 和正式网址复核。完整记录见 [上线验证](docs/v19-live-verification.json)。

## 本地浏览

直接打开 `index.html` 即可使用。推荐当前版本的 Chrome、Edge、Firefox 或 Safari。

## 主要互动

- 七幕电影式房间使用 26 张独立关键帧：页面按原生滚动位置在双层舞台中连续换帧和轻推镜头，不劫持滚轮、不强制分页
- “轻轻看看房间”观察模式支持鼠标拖动与滚轮、触摸拖动与双指缩放、双击、按钮和键盘方向键；手机按需读取 1440 档，桌面按需读取 4K
- 顶部“让房间静一静”会保存 `motionMode`；系统 `prefers-reduced-motion` 始终优先，并关闭连续混合、自主动作、雨景与视差
- 敲门后的受惊、害羞与开门表情演出
- 顶部房门纸签提供无地址片段的页内移动：站在门外时先完成敲门回应再进入目标区段；新访客稳定停在房门首屏，浏览器返回或前进会恢复原来的阅读位置，旧的 `#living-room` 一类地址会被清理并回到顶部
- “会生活的房间”：沿同一条木轨在画桌、床边、衣橱与窗台移动；每个地点都有自主细节、专属开场语音、三组独立语音事件、键盘方向键和手机横滑支持
- “今晚别走太早”深夜陪画：选择陪伴方式、画面主题、配色与一句具体感想；从第一步起保存未完成稿纸，刷新后可以接着画，也可以换一张空白稿纸重新开始
- 画桌与深夜陪画共用四张清晰赛璐璐风人物帧，晚安场景使用独立清晰版夜窗插画；不再用厚涂、水彩柔焦或额外十字窗框遮挡人物
- 选择“安静坐在旁边”后进入可随时离开的停留分支；20、45、75 秒各出现一个可见的角色变化，页面隐藏或离开该区段时暂停累计，最后一个节点仍是害羞回应，不会冒充完成画稿或发放奖励
- 选定小猫主题后，人物舞台内会出现“偷看画到哪里了”：稿纸先露出画面、再被慌张盖住、最后只害羞地露出一角；前三次偷看有不同的简体中文反应，不调用既有日语音频
- 五套服装与衣橱相册切页，包括草莓睡前服与符合家里蹲画师性格的猫耳连帽毯
- 一张完整画桌插画里的五个秘密；停留或在画面中寻找一会儿会出现贴合物件的微光线索，发现后留下很轻的薄荷猫爪痕迹，不显示提示按钮
- 十一张分成三章的小故事画稿；主图可进入沉浸暗房，支持方向键、手机滑动与原图细节放大，缩略胶片只在自己的横向轨道内居中，不会把整页拖到画册
- 四个主线语音入口、二十二句本地日语回答；普通池以十八句轻声、开心或害羞回答轮换，四句不高兴回答只在短时间连续催门或催稿时出现
- 房间另有十八句不与主线复用的专属日语语音：四个地点开场、十二个地点事件、雨起与雨停各一条；每条都绑定独立 MP3、日文、简体中文字幕、场景名和反应
- 音量、停止与“只看角色字幕”控制；四个地点的十二次操作分别使用十二份动作匹配的 CC0 现场录音，两段天气声和一段晚安关门声另行独立，共十五段 48 kHz 立体声场景声；它们可单独关闭、不自动播放、不循环，并只在访客主动按下控件或播放时准备
- 雨景按每张插画的玻璃轮廓独立裁剪：Canvas 使用随窗帘、人物头发与斜窗框收口的多边形遮罩，桌边、衣橱、窗台和共同创作使用不同节奏，床边及室内不下雨；晴月状态会同时清空房间与共同创作雨层
- 窗雨声使用 nicoproson 在室内录制的真实轻雨窗玻璃声（Freesound 648529，CC0 1.0），处理为 24.024 秒、48 kHz、立体声、192 kbps 本地 MP3；来源哈希、处理参数和复现脚本均随仓库保存
- 三阶段回访文案：初次、逐渐熟悉与主动留门缝，不使用签到或数值好感度；门口纸角会在已收纸条、共同成稿、十二个房间事件和成功换装之间，按真实发生时间展示最新一项
- 晚安小纸条优先引用本次拜访实际完成的画、触发的房间动作或成功换装；只有同一次拜访里的事实才会组合，不跨拜访虚构经历。纸条可收下并在下次回来时保留，收下后会播放真实木门轻合声并完成关门告别
- 七幕新增二十八句“つくよみちゃん”Piper Plus 日语语音与二十一份互不复用的 CC0 物件拟音；只有主动点击观察热点或轻声呼唤角色才播放，单纯滚动、自动换帧和页面加载始终无声

## 使用技术

页面仅使用原生 HTML、CSS 和 JavaScript，不依赖框架、后端或运行时外部服务。浏览器状态继续保存在 `sagiri-room-state-v2`；V19 只新增 `motionMode`，旧状态回落到“活泼”，其他画稿、记忆、声音与换装字段保持原结构。中文标题和日语字幕分别使用 ZCOOL KuaiLe、Noto Sans JP 的当前字符子集 WOFF2。

V19 七幕素材位于 `assets/v19`：8 张 3072 × 3840 竖版人物与 18 张 3840 × 2880 场景组成 26 张母版，连同 480 / 720 / 1440 派生图共 96 个 WebP。普通连续舞台在手机使用 720 档、桌面使用 1440 档；只有主动打开观察模式时，手机升级到 1440，桌面升级到 4K。`CinematicDirector` 使用双图片层、`IntersectionObserver`、被动 `scroll` 监听与 `requestAnimationFrame` 合并更新，并以加载序列号阻止旧请求覆盖新镜头；开启 Save-Data 或处于 2G 时停止邻帧预取。

最终 V19 插画使用清爽明亮、平整无纹理、最多两档阴影的日系 TV 动画赛璐璐风。首轮新图因棕橙、颗粒和油画脏感被整体隔离，没有进入 `assets/v19`；最终图以干净校准图重新逐图编辑，再由 Pillow Lanczos 纯缩放导出，不添加锐化、纹理、降噪或调色滤镜。V18.1 的 107 个 WebP 与更早图片均保留，`assets/archive/pre-v19-cinematic-images.json` 保存切换前的路径、尺寸、大小与 SHA-256。

## 自动验证

直接浏览页面不需要安装依赖；维护自动检查需要 Node.js 22 或更高版本。安装开发依赖后可运行：

```powershell
npm ci
npm run verify
npm run test:e2e
```

`npm run verify` 检查 JavaScript 语法、HTML ID 与锚点、页面本地资源、V18 / V19 图片矩阵与归档、V19 语音和拟音清单、JSON、UTF-8 无 BOM 和乱码特征；`npm run test:e2e` 使用 Chromium 覆盖旧功能与 V19 七幕滚动、快速反向滚动、观察模式、动态偏好、设备图片档位和声音隔离。`npm test` 会依次执行两者。

V18 的图片维护入口如下；单张 ImageGen 输出如何生成母版与派生图，以及每个参数的含义，见 [V18 全量 4K 插画重绘记录](docs/v18-4k-image-redraw.md)。

```powershell
$env:PYTHONUTF8="1"
python tools\build-v18-archive-manifest.py
python tools\build-v18-manifest.py
```

V19 清理源图、图片清单和二十一段拟音的构建入口如下；详细合同见 [V19 七幕电影式房间](docs/v19-cinematic-room.md)与 [V19 语音复现](docs/v19-voice-reproduction.md)。

```powershell
$env:PYTHONUTF8="1"
npm run images:v19-archive
npm run images:v19
npm run images:v19-manifest
npm run audio:v19-foley
npm test
```

## 声音与字体说明

- 语音使用 AivisSpeech 的“天深シノ”模型生成；二十二句回答均为独立合成内容，保留完整 `audio_query`，使用同一模型并按场景选择轻声、普通、开心或情境限定的稍微不高兴表达，遵循 ACML-NC 1.0，仅用于个人非盈利展示。
- 房间专属语音使用 Piper Plus 的“つくよみちゃん”预训练模型生成；十八句均为本次房间独立文本和独立音频，不复用前述二十二句，也不使用说话人克隆。模型输出按其语料条款使用并在页脚保留来源。
- V19 七幕另有二十八句“つくよみちゃん”Piper Plus 独立语音。固定源码提交、模型 revision / SHA-256、逐句参数、查询 JSON 与验收结果见 [`assets/audio/v19/voice-manifest.json`](assets/audio/v19/voice-manifest.json)和 [V19 语音复现](docs/v19-voice-reproduction.md)；合成使用 256 维零向量、mask 0，不提供参考音频，不训练、微调、克隆或后期移调。
- V19 的二十一个观察热点各使用一份不同的 Freesound CC0 实录，只在主动点击时播放；来源与处理记录见 [`assets/audio/v19/CINEMATIC-FOLEY-SOURCES.md`](assets/audio/v19/CINEMATIC-FOLEY-SOURCES.md)。
- 画桌、床边、衣橱与窗台的十二次操作使用十二份不同的 Freesound CC0 实录；每份只截取一个与页面动作相符的物件表演，不使用程序化噪声，也不把同一来源拆成多个事件。完整来源、取得哈希与处理参数见 [`assets/audio/v14/ROOM-FOLEY-SOURCES.md`](assets/audio/v14/ROOM-FOLEY-SOURCES.md)。
- 晚安关门使用 CastIronCarousel 的 [`Slow gentle close of squeaky wooden door.wav`](https://freesound.org/s/216877/) 官方 HQ 预览节选，依据 CC0 1.0 使用；完整取得信息见 [`assets/audio/v16/GOODNIGHT-DOOR-SOURCE.md`](assets/audio/v16/GOODNIGHT-DOOR-SOURCE.md)。
- 天气·雨落窗外使用 nicoproson 的 [`RAIN on glass window.wav`](https://freesound.org/s/648529/) 官方 HQ 预览节选，依据 CC0 1.0 使用；完整取得信息见 [`assets/audio/v8/RAIN-SOURCE.md`](assets/audio/v8/RAIN-SOURCE.md)。
- 中文手写标题使用站酷快乐体，日语字幕使用 Noto Sans JP；两者均遵循 SIL Open Font License 1.1，并以本地字符子集加载。
- 页面不包含动画原声、声优声纹克隆或官方截图。
