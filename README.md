# 和泉纱雾的房门里

一个零框架、无后端的个人非盈利同人角色互动页。沿着“轻轻敲门”的叙事，可以探索纱雾的画桌、陪她完成一张小猫画、切换五套日常服装、按章节查看秘密画稿，并播放带简体中文字幕的本地日语语音。页面会记住间隔较久的再次拜访，也会留下上次共同完成的画，但不显示好感度数值。

在线访问：<https://xinchenok.github.io/izumi-sagiri-room/>

## 本地浏览

直接打开 `index.html` 即可使用。推荐当前版本的 Chrome、Edge、Firefox 或 Safari。

## 主要互动

- 敲门后的受惊、害羞与开门表情演出
- “今晚，陪她画完这一张”共同创作：选择陪伴方式、画面主题、配色与一句具体感想；结果会改变成稿、角色台词和下次回访记忆，没有分数、奖励或失败状态
- 五套服装与衣橱相册切页，包括草莓睡前服与符合家里蹲画师性格的猫耳连帽毯
- 一张完整画桌插画里的五个无常驻标记秘密；停留一会儿会收到一句自然线索，不显示提示按钮
- 十一张分成三章的小故事画稿；主图可进入沉浸暗房，支持方向键、手机滑动与原图细节放大
- 四个语音入口、二十二句本地日语回答；普通池以十八句轻声、开心或害羞回答轮换，四句不高兴回答只在短时间连续催门或催稿时出现，并始终显示对应简体中文字幕
- 音量、停止与“只看字幕”控制；声音不会自动播放，也不混入通用循环环境音
- 三阶段回访文案：初次、逐渐熟悉与主动留门缝，不使用签到或数值好感度
- 随机晚安小纸条

## 使用技术

页面仅使用原生 HTML、CSS 和 JavaScript，不依赖框架、后端或运行时外部服务。状态保存在浏览器本地存储中。首屏、表情与换装使用完整尺寸高质量 WebP，并按屏幕选择 560px 移动版本；共同创作舞台使用 1448 × 1086 / 720 × 540 两档本地 WebP，标题字体使用当前页面字符子集 WOFF2，画册只预取当前页相邻内容。

[AI 协作开发与维护手册](docs/ai-assisted-development.md)记录了逐阶段实施与修复账本、AI 协助完成的工作、插画方法、语音模型官方来源与本地合成流程、许可边界、上线验证和后续规划；[V6 共同创作插画记录](docs/drawing-v6-image-prompts.md)保存本轮场景与成稿的生成方向、导出规格和校验值。语音使用预训练模型本地合成，本项目没有训练或克隆声优声纹。

## 声音与字体说明

- 语音使用 AivisSpeech 的“天深シノ”模型生成；二十二句回答均为独立合成内容，保留完整 `audio_query`，使用同一模型并按场景选择轻声、普通、开心或情境限定的稍微不高兴表达，遵循 ACML-NC 1.0，仅用于个人非盈利展示。
- 手写标题字体为站酷快乐体，遵循 SIL Open Font License 1.1。
- 页面不包含动画原声、声优声纹克隆或官方截图。
